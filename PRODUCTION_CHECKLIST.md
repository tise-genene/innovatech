## 📋 Production Commands

```bash
# Development
npm run dev

npm run build

# Start Production Server
npm start

# Lint Check

```

## 🌐 Deployment Steps (Vercel)

1. Push code to GitHub
2. Import project to Vercel
3. Configure environment variables
4. Deploy!

```bash
# Or use Vercel CLI
npm install -g vercel
vercel --prod
```
